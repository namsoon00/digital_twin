# 월드 상태와 사건 이력

## 현재 운영 경계

MarketWorld는 시장 관측, KnowledgeWorld는 기업·증권·출처·관계,
PortfolioWorld는 계좌별 보유·정책·판단 맥락을 소유한다.
SharedPremiseWorld는 구현돼 있지만, 증분 현재 상태 추론에서는 오프라인
대조·마이그레이션 용도다. 실시간 알림을 위해 별도 공유 전제 세대를
만들 필요는 없다. `global` 식별자는 전 세계 정보의 완전한 수집을 뜻하지 않는다.

## 진단 계약

`/api/ontology/diagnostics`는 현재 active/delivery 배포의 연결을 먼저 읽는다.
시장·지식·공유 전제 조회는 공유 그래프, 계좌 조회는 운영 배포 그래프를 선택한다.
배포 ID, 제어 버전, 두 그래프 연결 및 선택한 연결이 캐시 키에 포함된다.
연결을 확인할 수 없으면 이전 배포의 캐시로 대체하지 않는다.
상세 저장소 조회는 기존 백그라운드 캐시 경로를 사용한다.

`observation`은 응답 생성 시점과 캐시 상태를 함께 평가한다. 60초를 지난
진단은 과거 관측이며, 시점 누락·미래 시각·시간대 없는 시각은 미확인이다.
갱신 중·갱신 실패를 별도로 표시한다. 최근 진단이라는 사실은 원천 정보의
정확성·최신성·충족도에 대한 승인으로 사용하지 않는다.

`worldInventory`는 선택한 그래프 저장소에서 실제 관측한 월드 목록과
각 활성 투영의 시점·범위 수를 제공한다. 공유·계좌 저장소가 다르면 각
worldId로 조회해야 한다. 목록을 읽지 못한 경우 빈 월드로 단정하지 않는다.
원천 최신성과 내용 충족도는 `not-assessed`이며, 범위 수가 종목 수나
정확도 점수로 표시되어서는 안 된다.

## 사건 이력 계약

`news_intelligence.public.build_event_history`는 피드 외 소비자도 사용할 수
있는 읽기 전용 공통 계약이다. 상세 근거 API의 `eventHistory`가 이를 사용하며
기존 `storyTimeline`도 유지한다. 새 투자 사실·주장·행동 권한은 생성하지 않는다.

- 동일 종목·자료 종류에서 기록된 `eventEpisodeId`를 우선 사용하고,
  없으면 `storyClusterId`, 둘 다 없으면 선택한 근거 한 건만 사용한다.
  제목 유사도나 같은 날짜만으로 서로 다른 사건을 합치지 않는다.
  실적 에피소드의 연도가 없는 분기·기간 미확인 기록은 한 건으로 제한한다.
- 발행 시각 순으로 표시하고 미확인 시각은 끝에 둔다. 수집·발표·효력
  발생 시각과 보고 기간은 따로 보존하며 서로 대신하지 않는다.
- 정정 대상 문서, 대체 근거, 상충 근거는 저장된 계보에서만 가져온다.
  앞뒤 기사의 문구 차이로 정정이나 인과관계를 만들어내지 않는다.
- 저장소 조회는 최대 20건, 화면 계약은 기본 12건이며 선택한 근거는 유지한다.
  보관 기한으로 사라진 자료가 있을 수 있으므로 항상 `retained-sample`,
  `historyComplete=false`다. 원문 URL은 HTTP(S)만 허용한다.
- 출처 수와 독립 검증 수는 다르다. 이력이 여러 건이라는 이유로 근거의
  신뢰도나 기존 판단 적격성을 승격하지 않는다.

이 계약은 현재 보관 중인 문서들의 이력이다. 같은 evidence ID의 과거 원문
개정 전체를 복원하는 저장소나 국가 간 장기 사건 추적기는 아니다.

## 다음 확장과 완료 기준

| 순서 | 확장 | 완료 판단에 필요한 증거 |
| --- | --- | --- |
| 1 | 수집 범위·출처 품질 | 대상 국가·산업·종목별 미수집/미지원/실패 구분, 독립 원출처 계보, 실제 복구 수집 결과 |
| 2 | 일반 사건의 장기 이력 | 기업 외 주체·대상 객체를 포함한 사건 식별, 원문 개정 보존, 정정·철회의 명시적 연결, 기간을 넘는 잘못된 병합 회귀 검증 |
| 2 | 공급망·산업 노출 | 상대 기업 식별, 매출·조달 비중의 단위·기간·근거, 관계 재확인 및 만료 정책 |
| 2 | 국가·정책·지정학 | 공식 원문과 관할 국가, 적용 품목·산업, 발표/시행/종료일, 상충 주장 및 번역 원문 연결 |
| 2 | 거시경제 흐름 | 발표 당시 통계와 후속 개정값 구분, 기준 기간·단위·발표 시점, 당시 이용 가능 자료만 사용하는 재현 |
| 3 | 시나리오 | 관측 사실과 가정 분리, 검증 가능한 전달 경로, 가상 결과가 운영 판단에 섞이지 않는 경계 |

새 영역은 먼저 기존 소유 월드의 개념·관계와 원천 데이터 계약으로 확장한다.
별도 DB·워커는 독립 운영 요구가 입증된 경우에만 추가한다. 장기 이력을
현재 상태 그래프나 화면 피드만으로 보존하지 않는다.

## 검증

범위·기간 격리, 원문 상태·시점 유지, 제한된 보관 이력, 배포별 캐시 격리,
오래된 진단·미확인 값 및 화면 이스케이프를 검증한다.
